🚀 FUDDO Setup Complete

Guía rápida para completar la configuración del sistema de registro

¡Sistema listo! Sigue estos 3 pasos para activar el registro con email automático.
1

📦 Instalar Dependencias

Instala PHPMailer para el envío de emails automáticos.

Opción A: Con Composer (Recomendado)

composer install

Opción B: Sin Composer

Descarga de: GitHub PHPMailer

2

🗄️ Crear Tablas

Initializa la base de datos con las tablas necesarias.

Se crearán automáticamente:

  • usuarios_master
  • restaurantes
  • auditoria_registros
3

📧 Configurar Email

Edita el archivo de configuración de email.

Archivo:

config/mail_config.php

Con Gmail:

Habilita 2FA en tu cuenta Google y genera una contraseña de app

Checklist Final

Cuando todo esté listo: Ve a registro.php para probar el sistema.
